## 今天修复的问题

### 1. 点歌后几秒跳回首页、无播放状态(核心崩溃)

- 根因:refresh 内直接 `show()` 的 use-after-free(删屏后调用方还在操作控件)
- 修复:延迟导航 `m_pendingNavigate`,由 `HifiUi::refresh()` 所有页面分支执行完后统一切页;
  一次性"已开播"闩锁加锁保护;snapshot 对 CloudMusic 源填充真实 title/detail

### 2. 设置里网关一直"唤醒不了"(内部 RAM 耗尽 → TLS 分配失败)

- 根因:空闲内部堆仅 13KB,mbedTLS 握手需 ~40KB 连续堆 → 每次 TLS 连接失败;
  电台是纯 HTTP 不需要 TLS,所以正常
- 修复:云端结果数组(搜索/歌单/榜单/新歌)全部迁 PSRAM,释放 ~24KB 内部 RAM;
  任务栈回到实测安全值;实测空闲堆 13.3K → 54.7K,设备端健康检查通过
- 沉淀经验:大数据放 PSRAM,任务栈不盲目加大

### 3. 浏览 502(双服务冷启动)

- 根因:Render 免费层网关和上游各自休眠,健康检查只醒网关,上游仍冷 → 浏览秒回 502
- 修复:网关新增 `/esp/v1/wake`(90s 长超时等上游就绪);固件唤醒任务两段式
  (健康检查 → 预热上游,"已连接"即保证浏览可用);在线音乐首页进入也触发唤醒

### 4. 列表乱码 + 排版不合理

- JSON 解析器补 `\u` 代理对(surrogate pair)合并,emoji 不再变非法 UTF-8
- 新增 `cloudTextSanitize()`:解析时剥离字体(Noto Sans SC 13px 子集)无法渲染的非 BMP/控制字符
- 排版:32px 行两行 17px 行高文字重叠、VIP 徽标压字 → 统一本地同款 40px 行
  (LEFT_MID ±10)布局,徽标右中对齐,有徽标时文字宽度 205 避让

### 5. 分类点击显示 SETTINGS/EQ 占位页

- 根因:新增 5 个页面只加了 Page 枚举,漏加 `show()` 分发链
- 修复:补全分发(顺带激活了从未渲染过的在线播放页)

### 6. 播放交互(点歌反应慢/没反馈、返回跳主页、封面问题)

- 点歌立即进入播放页,显示"正在连接…",失败直接显示原因(不再静默)
- 播放页 LIST 槽打开当前队列来源列表;新增 `showKeepingStack` 保留页面栈,
  滑动返回回到播放页而非主页(原 show() 祖先截断导致回首页)
- 专辑封面缺失时用当前歌单/榜单封面兜底;封面解码比例 8→4 并始终铺满 72px 槽

## 架构要点(家里电脑必读)

- **队列上下文**:`m_cloudQueueSource`(Search/Playlist/NewSongs)+ 索引,
  上一曲/下一曲在来源列表内循环;云端曲目 EOF 自动播队列下一首
- **延迟导航**:任何页面 refresh() 内不得直接 show();统一走 `m_pendingNavigate` 于 refresh 末尾应用
- **PSRAM 策略**:所有云端大数据数组(搜索/歌单/榜单/新歌/歌词)在 setup() 用 `ps_malloc`,
  内部 RAM 只留给 TLS(~40KB 连续堆)与 UI;访问全部走 `s_cloudResultMutex`
- **任务栈实测值**:cloudCtrl 12K、cloudWake 8K、cloudDiag 16K、歌词/封面/缩略图任务 8K
- **歌词双轨**:本地(ID3 SYLT + lrclib.net)与在线(网关 lyrics)独立存储,互不干扰
- **防睡眠**:`cloudKeepaliveTask` 每 9 分钟 健康检查 + `/esp/v1/wake`(仅 WiFi 连接且已配置时)
- **设备诊断接口**:`/cloud_diag_start` + `/cloud_diag_json`(heap → DNS → TCP443 → TLS 健康检查,
  逐步上报);websocket 端口 81 发 `test` 可查实时堆内存

## 网关接口清单(services/ncm-gateway)

- `GET /esp/v1/health` — 无鉴权健康检查
- `GET /esp/v1/wake` — 预热上游(90s 长超时),防睡眠与唤醒用
- `GET /esp/v1/search` / `playlists/hot(?cat=)` / `playlists/:id` / `rankings` / `new-songs`
- `GET /esp/v1/tracks/:id/resolve` / `tracks/:id/lyrics`
- 设备密钥鉴权 `X-Device-Key`;rateLimit + TTL 缓存;resolve 永不缓存
