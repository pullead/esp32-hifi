Status bar

3 groups only: Wi-Fi icon, one confirmable audio-state tag (I2S/AMP/BUFFERING/MUTE), volume bars. No clock, no SSID, no separate DAC chip — down from 6 chips in the previous UI.

Control bar

5 equal 64×46 columns, same slots in both modes (EQ↔Favorite, list↔station list) — one shared grid for Music and Radio, per handoff §7/8.

Not shown here

Sd / Clock / Settings screens (still placeholders in code), volume popup, EQ page, station list page — out of scope for this pass.
